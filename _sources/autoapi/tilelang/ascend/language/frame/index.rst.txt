.. py:class:: SimtVFFrame

   Bases: :py:obj:`tvm.tirx.script.builder.frame.TIRFrame`


   Frame for SimtVF (SIMT Vector Fixed) region.

   The C++ frame generates the ``SIMT_VF`` block and its thread-extent
   bindings. The Python frame additionally maintains the active SIMT context.


   .. py:method:: __enter__()


   .. py:method:: __exit__(ptype, value, trace)


.. py:function:: SimtVF(threads = 128, latency = 0)

   Construct a dedicated SIMT vector-fragment region frame.

   :param threads: Thread count for the SimtVF frame. A sequence may contain up to three
                   dimensions; omitted dimensions default to one.
   :type threads: int | list[int] | tuple
   :param latency: Measured latency in cycles. Zero uses the scheduler's latency model.
   :type latency: int

   :returns: **res** -- The SimtVFFrame used to denote a SIMT vector-fragment region.
   :rtype: SimtVFFrame
