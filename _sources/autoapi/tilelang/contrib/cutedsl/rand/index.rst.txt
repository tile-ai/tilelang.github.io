tilelang.contrib.cutedsl.rand
=============================

.. py:module:: tilelang.contrib.cutedsl.rand

.. autoapi-nested-parse::

   Philox4x32-10 random numbers for the CuTeDSL backend.

   This is a port of the ``curandStatePhilox4_32_10_t`` part of
   ``curand_kernel.h``. The generator state lives in a 16-word register array
   because it has to survive across conditional code, which is how curand keeps
   it in a local struct.

   Integers and uniform floats reproduce curand bit for bit. The normals run the
   same Box-Muller transform with the same cached sibling and the same fast
   sin/cos, but that approximation is not bit-identical to curand's ``__sincosf``
   for every input, and the double pair uses ``sincospi``, which CuTeDSL does not
   expose; both agree to a few ulps and the generator position always matches.

.. py:function:: rng_uniform2_double(state, out, *, loc=None, ip=None)

   Fill two doubles with ``curand_uniform2_double``, which draws one block.

   The 64-bit uniform store is the one place where curand's vector helper is
   not the elementwise composition of its scalar form: it takes 53-bit samples
   from a whole Philox block instead of one 32-bit word per result.


.. py:function:: rng_normal2(state, out, *, loc=None, ip=None)

   Two float32 normals, like ``curand_normal2``.

   curand's vector helpers generate a fresh pair and keep the scalar
   Box-Muller cache as it is, so a later scalar draw still returns its
   sibling.


.. py:function:: rng_normal4(state, out, *, loc=None, ip=None)
